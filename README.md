📚 Lessons Learned — Week 2: CSS Mastery

1. CSS Variables Make Everything Easier to Change
Defining colors and font sizes as custom properties in :root:

css
:root {
    --accent: #22d3ee;
    --font-2xl: 1.5rem;
}

...means I can change the entire site's accent color by editing one line instead of hunting through hundreds of CSS rules. This is the single biggest quality-of-life improvement I've learned so far.CSS isn't just "make it look pretty." It's a design system — colors, spacing, typography, and layout are all connected.
